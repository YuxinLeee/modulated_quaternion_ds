# Modify Orientation 实验任务场景

这里列的是**需要在中途改变末端朝向**的操作任务，适合用来做“modify orientation”实验（类似：倒水 → 遇障 → 改朝向）。

---

## 1. 倒水遇障改朝向（Pour + Obstacle）

- **原始意图**：从 A 向杯子 B 倒水，壶嘴保持某一倾斜角。
- **障碍**：路径上出现障碍物（或桌沿、架子），直着过去会碰撞。
- **改 orientation**：在靠近障碍时临时抬壶嘴/侧倾（改 roll/pitch），绕过障碍后再恢复倒水姿态，最后仍对准杯子。
- **实验点**：障碍在不同高度/位置时，需要不同的“抬多少、何时恢复”。

---

## 2. 插拔/插孔遇限位（Insert + Clearance）

- **原始意图**：抓取插头/插销，沿直线插入孔位，末端姿态与孔对齐。
- **限位**：孔口有遮挡或只有一侧开口，不能一直保持同一朝向插入。
- **改 orientation**：接近孔口时先偏一个角度（yaw/roll）从开口侧进入，进入后再拧回目标姿态插到底。
- **实验点**：不同孔口方向、不同“先偏再拧回”的幅度。

---

## 3. 拧瓶盖/旋钮（Twist Cap / Valve）

- **原始意图**：手爪抓住瓶盖，绕瓶轴旋转拧开。
- **改 orientation**：若手臂在奇异点附近或空间受限，不能一直用同一腕部朝向拧到底；需要在拧的过程中**分段改变腕部朝向**（例如半圈换一次握姿），但旋转轴仍对准瓶轴。
- **实验点**：拧多圈、不同瓶高/位置时，规划几段不同的末端朝向。

---

## 4. 从狭缝/抽屉取放（Slot / Drawer）

- **原始意图**：把物体放进狭缝或抽屉，末端姿态与缝/抽屉对齐。
- **改 orientation**：入口很窄，必须以“斜着进”（先偏 yaw 或 roll）进入，进入后再摆正放置；取出时反之，先摆正再斜着出。
- **实验点**：缝的朝向、深度不同，需要的“进—摆正—放”的 orientation 序列不同。

---

## 5. 绕过人体/易碎物（Human / Fragile Avoidance）

- **原始意图**：末端抓物体从一侧移动到另一侧（例如从左到右放物）。
- **改 orientation**：路径中间有人或易碎物，不能只靠平移；需要**临时把物体“立起来”或“转一下”**（改 pitch/roll）从上方或侧面绕过，过了再恢复水平搬运姿态。
- **实验点**：障碍高度、宽度不同，需要的“抬多高、转多少”不同。

---

## 6. 多目标依次对准（Re-targeting）

- **原始意图**：先对准目标 A（如摄像头对准标签 1），再对准目标 B（标签 2）。
- **改 orientation**：从 A 到 B 若直线转过去会碰到障碍或奇异，需要**中间插一个过渡朝向**（先转到某个安全姿态，再转到 B），形成 A → 过渡 → B 的 orientation 轨迹。
- **实验点**：A/B 相对位置、中间障碍，导致不同的过渡姿态。

---

## 7. 刮/擦表面换角度（Wiping / Scraping）

- **原始意图**：刮刀/抹布沿直线刮某一方向。
- **改 orientation**：刮到边缘或凸起时，需要**临时改变刀面/布面相对表面的倾角**（改 pitch/roll）以免卡住或刮坏，过了再恢复。
- **实验点**：不同边缘形状、凸起高度，对应不同的“临时倾角”和恢复时机。

---

## 8. 开门/拉把手（Door / Handle）

- **原始意图**：手抓住门把，绕门轴旋转开门。
- **改 orientation**：若门把在侧面或门半开，手臂可能贴门/碰框；需要在拉的过程中**改变手爪相对门把的朝向**（例如从“握”换成“勾”再拉），轨迹仍是绕门轴。
- **实验点**：门把类型、门开角、手臂与门相对位置，导致不同的握姿切换点。

---

## 9. 叠放/码垛时避碰（Stacking / Palletizing）

- **原始意图**：把箱子放到指定格子，末端水平放置。
- **改 orientation**：格子一侧有已放箱子或挡板，水平直接放会碰；需要**先斜着进**（改 roll/pitch）再在格子内摆正放下。
- **实验点**：格子深度、已有箱高度，决定“斜多少、何时摆正”。

---

## 10. 倒水换目标杯（Pour Re-target）

- **原始意图**：从壶往杯 1 倒水。
- **改 orientation**：倒到一半时杯 1 满了或需要换杯 2；**在不洒的前提下改变壶嘴朝向**，从对准杯 1 平滑转到对准杯 2。
- **实验点**：两杯相对位置、壶当前姿态，决定转动的轴和角度。

---

## 小结

| 任务           | 典型“改朝向”原因     | 主要变化轴   |
|----------------|----------------------|--------------|
| 倒水遇障       | 避障                 | roll / pitch |
| 插孔遇限位     | 从开口侧进入         | yaw / roll   |
| 拧瓶盖         | 避免奇异/换握姿      | 绕瓶轴 + 腕部 |
| 狭缝取放       | 窄口先进再摆正       | yaw / roll   |
| 绕人/易碎      | 抬升/侧绕            | pitch / roll |
| 多目标对准     | 中间过渡姿态         | 多轴         |
| 刮擦换角度     | 边缘/凸起            | pitch / roll |
| 开门/把手      | 握姿切换             | 多轴         |
| 码垛避碰       | 斜进再摆正           | roll / pitch |
| 倒水换杯       | 换目标               | yaw / pitch  |

做实验时可以选 1～2 个任务（例如**倒水遇障**、**狭缝取放**），在仿真或真机上录“原始轨迹 + 遇障/限位后改朝向”的演示，用你现有的 modify orientation / modulation pipeline 做学习与重现。
